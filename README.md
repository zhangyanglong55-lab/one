# 系统文章思考 Skill

这是一个面向中文现实写作的系统分析 Skill。你给出主题或参考资料，它会选择少量互补的思维框架，检查事实、利益、反馈、演化、组织能力、权力边界与二阶后果，再把分析交给自然中文写作流程。

它的目标不是在文章里罗列理论名词，而是让理论在后台工作，让正文仍然像一个真正理解事情的人在说话。

## 适合什么任务

- 公众号、知乎、博客和行业评论
- 产品、商业、组织与社会议题分析
- 历史解释与政策讨论
- 需要多角度、系统性、因果链或反方检验的文章
- 需要结合“活人感”中文写作的现实长文

## 核心能力

- 从系统动力学、复杂适应系统、博弈论、VSM、批判系统思维等框架中选择最小组合
- 按参与者、资源、激励、反馈、延迟、适应与代价组织分析
- 区分事实、推断和未知，处理反例与替代解释
- 将抽象概念翻译成可读的角色、行动、因果和后果
- 默认隐藏框架名称，只在用户要求时提供简洁的方法说明

`SKILL.md` 保存核心流程，其余文件按需提供框架路由、观点质疑、文章转换和活人感写作交接规则。

## 使用方式

将 `systemic-article-thinking` 整个目录作为 Skill 安装到支持 Skills 的环境中，然后直接提出任务。

```text
@systemic-article-thinking
请根据这些材料写一篇“AI 赋能医疗”的文章。面向普通读者，重点分析医院、医生、患者、技术公司和监管者之间的关系，不要在正文里罗列理论名称。
```

也可以要求它解释方法。

```text
请在文章之后，用简短清单说明你使用了哪些思考框架，以及每个框架对结论有什么贡献。
```

## 与活人感写作配合

这个 Skill 负责把问题想透，并在写作阶段调用 `human-writing` 完成自然中文表达。若运行环境没有该 Skill，仍可使用本 Skill 的分析部分，但需要自行补充写作风格约束。
