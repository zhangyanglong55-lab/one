## 路由原则

先扫描问题，再选择框架。关键词只能提示可能方向，不能直接决定框架。

框架选择遵守四条规则。

1. 选择能够解释不同层级或不同机制的框架。
2. 每增加一个框架，都要带来新的问题、证据要求或反例。
3. 两个框架只是在换词重复同一观点时，保留解释力更强的一个。
4. 用户指定框架时优先使用，同时检查它是否适合材料和问题。

一般系统论作为底层语法，帮助识别边界、层级、环境、输入输出、整体关系和开放性。它不必在正文中单独出现。

## 通用扫描

每个主题先回答五个问题。

1. 事情怎样发展到今天，关键变化发生在什么时候。
2. 系统中有哪些参与者，他们掌握什么资源，追求什么利益，承担什么代价。
3. 哪些行为形成强化反馈，哪些力量形成抑制反馈，哪里存在延迟。
4. 参与者会不会学习、适应、模仿并改变原来的规则。
5. 当前边界遗漏了谁，分析采用了谁的视角，谁没有发言权。

扫描只负责暴露问题，不生成最终结论。

## 框架选择表

| 框架 | 优先使用的情形 | 它主要追问什么 |
| --- | --- | --- |
| 唯物辩证法 | 内部矛盾、量变积累、条件变化、事物转化 | 哪组矛盾推动变化，转化需要哪些条件 |
| 历史唯物主义 | 生产方式、技术、制度、所有权和社会关系长期变化 | 物质条件、利益结构和制度怎样共同塑造历史 |
| 系统动力学 | 长期积累、反馈、延迟、政策反作用 | 哪些回路维持现状，存量怎样形成，干预为何失效 |
| 复杂适应系统 | 多主体互动、学习、适应、涌现和不可预测变化 | 局部规则怎样产生整体秩序，主体会怎样改变规则 |
| 芒格多元思维 | 跨学科决策、单一解释风险、现实判断 | 还缺少哪门学科的模型，激励和认知偏差怎样影响结果 |
| 二阶控制论 | 观察、测量和干预改变被观察对象 | 观察者如何进入系统，指标怎样改变行为 |
| 博弈论 | 多方竞争、合作、背叛、谈判和激励错位 | 各方策略、收益结构和稳定均衡是什么 |
| 认知建构论 | 各方对问题的定义和现实理解不同 | 人怎样建构问题，哪些分类和叙事影响行动 |
| 生态位思维 | 资源有限、位置竞争、差异化生存 | 主体依赖什么资源，空缺位置和替代者在哪里 |
| VSM | 组织层级、自治、协调、信息失真和生存能力 | 哪个管理功能缺位，局部自治与整体控制怎样失衡 |
| 软系统方法论 | 目标含混、利益相关者无法同意问题定义 | 各方世界观是什么，哪些改变既可行又能被接受 |
| 批判系统思维 | 权力、边界、受益者和代价承担者 | 谁定义目标，谁有决策权，谁被排除在边界外 |
| 网络科学 | 传播、关系结构、中心节点、集群和级联风险 | 连接结构怎样影响行为，关键节点和脆弱点在哪里 |
| 多主体建模 | 需要从个体规则推演宏观结果 | 哪些微观规则足以生成已观察到的整体模式 |
| 因果推断 | 需要判断干预是否真正造成结果 | 反事实是什么，混杂因素和选择偏差在哪里 |
| 贝叶斯思维 | 证据不完整、判断需要持续更新 | 先验判断是什么，新证据应使信念改变多少 |
| 韧性思维 | 冲击、临界点、恢复、适应和转型 | 系统靠什么吸收冲击，何时需要转型而非恢复 |
| SODA | 多方需要共同梳理问题和战略选项 | 各方认知地图怎样连接，哪些选项具有共同支撑 |
| 运筹学 | 资源配置、排程、约束和优化 | 目标函数、约束条件和可行解是什么 |
| 系统工程 | 复杂产品、项目和生命周期实施 | 需求、接口、风险和全生命周期怎样保持一致 |

## 典型组合

### 产品与技术竞争

优先考虑系统动力学、博弈论、复杂适应系统、生态位和历史唯物主义。

系统动力学处理增长与反馈，博弈论处理竞争行为，复杂适应系统处理用户和开发者的适应，生态位处理差异化位置，历史唯物主义处理技术背后的生产与组织关系。

### 组织管理

优先考虑 VSM、系统动力学、博弈论、认知建构论和批判系统思维。

VSM检查组织功能，系统动力学检查积累与延迟，博弈论检查激励，认知建构论检查各方怎样定义问题，批判系统思维检查权力与边界。

### 社会与公共议题

优先考虑历史唯物主义、唯物辩证法、系统动力学、复杂适应系统和批判系统思维。

先处理物质条件、矛盾与权力，再检查反馈、涌现和政策的意外后果。

### 历史解释

优先考虑历史唯物主义、唯物辩证法、演化思维、博弈论和生态位。

区分长期结构、积累条件、行动者策略与触发事件，避免把结果归因于单一人物。

### 风险与危机

优先考虑系统动力学、网络科学、韧性思维、贝叶斯思维和博弈论。

检查传播路径、临界点、冗余、证据更新，以及危机中各方策略变化。

## 常见误用

- 唯物辩证法不能把任何差异都叫矛盾，也不能跳过具体条件直接宣告转化。
- 历史唯物主义不能把每个事件都缩减成经济利益，文化、组织和偶然事件仍需材料分析。
- 系统动力学不能只画箭头，必须检查回路方向、存量、延迟和时间行为。
- 复杂适应系统不能把不可预测当作无法分析，仍要指出主体规则和互动机制。
- 芒格多元思维不能变成模型清单，模型必须改变当前判断。
- 二阶控制论不能让一切都滑向纯粹主观，外部约束和可核验事实仍然存在。
- 博弈论不能默认所有人信息充分且稳定理性，要检查学习、情绪、制度和权力差异。
- 认知建构论不能用不同理解抹平事实差异。
- 生态位不能只做生物学比喻，要指出资源、竞争者和环境约束。
- VSM不能把组织画成静态结构图，要检查信息、自治、协调和环境适应。
- 因果推断不能把相关关系直接写成因果关系。
- 批判系统思维不能只问立场，还要说明权力怎样改变资源、规则和结果。
